# lab-sigma-translate

Paste a Sigma detection rule and get the equivalent query for Splunk SPL, Elastic Lucene, or Microsoft KQL. Powered by [pySigma](https://github.com/SigmaHQ/pySigma) running in your browser via Pyodide.

Currently lives in the [randomcommits.dev](https://github.com/RandomCommits-dev/randomcommits.dev) monorepo at `lab-sigma-translate/`. Will move to its own repo when ready.

## Development

```bash
npm install
npm run dev
```

Requires Node 22.12+.
